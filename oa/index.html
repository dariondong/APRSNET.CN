活动简介

APRSNETCN-OA 是 APRSNET.CN 自己发起的一次空中通联活动。现在还没到活动时间。

OA 就是 On Air。参与者在 APRS 上互相通联，报文里带上报文前缀，机器人认这条前缀，把这一次通联记下来。活动名是 APRSNET.CN On Air，简称 APRSNETCN-OA，性质上是一次独立活动，非官方。

这一页先把规则的样子摆出来。机器人还没有上线，积分、徽章、排行榜也都没有。开放时间定了，会在这里公布。

参与方式（未开放）

参与方式还没开放。下面这几条是计划中的写法。

开放之后，参与者用 APRS 把带前缀的报文发给机器人。机器人收到后回一条确认，这一次通联就算记上。没有报名这一步。

  • 对象名APRSNETCN
  • 对象注释APRSNETCN-OA 或 OA
  • 报文前缀APRSNETCN-OA

未开放：现在发出去没有人收，也不会计入活动。

报文格式（预览）

两行报文的形状先摆在这里，字段顺序和取值都可能在开放前调整。

  • 上行：呼叫 APRSNETCN-OA CQ BG7XXX OL62 5W 前缀 + CQ + 对方呼号 + 网格 + 设备。
  • 下行：回应 APRSNETCN-OA ACK BG7XXX #001 +3 前缀 + ACK + 对方呼号 + 编号 + 这次加的积分。

图里的两行只是形状：CQ 是呼叫，ACK 是回应，+3 是这一次加的分。预览，尚未到活动时间，内容可能调整。机器人未上线，请勿发送。

积分规则（预览）

分值先按这套算，开放的时候再确认一遍。

走 RF 路径的分比走 APRS-IS 高。新网格、新呼号、每日首通各有加成，重复通联不积分。

  • RF 路径+3
  • APRS-IS 路径+1
  • 新网格+2
  • 新呼号+1
  • 每日首通+1
  • 重复通联不积分
  • 统计口径总积分 / RF 积分 / 网格数 / 呼号数

预览，尚未到活动时间，内容可能调整。
