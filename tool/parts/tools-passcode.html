passcode 计算器

连 APRS-IS 的登录行里要填一个 passcode，它只跟呼号有关。填上自己的呼号，这里替你算出来。

填 BG7LZQ 这样的大写呼号；带 SSID 的 BG7LZQ-9 也行，SSID 不参与计算。整行 user BG7LZQ pass … 粘进来也认得。算在浏览器里做，本站不发请求，也不存任何东西。

  • 它是什么 登录行里 pass 后面那串数字，服务器拿它确认呼号是你的。同一个呼号永远算出同一个数，带不带 SSID 都一样。
  • 只算自己的呼号 服务器只按呼号认人。拿别人的呼号登上去，发出去的包就都记在别人名下。
  • 算法是哪来的 官方文档没有公开它，各家开源客户端都在本地按同一套老算法算。这一页也一样，只在你自己的浏览器里跑。
  • 登录行怎么写 user、pass、vers 各填什么，pass 写 -1 就是只收不发。 →
