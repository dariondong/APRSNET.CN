参与贡献

这份资料是一个人一点点整理出来的，缺的地方还很多。你顺手补的那一句，可能就替后面的人省下半天。

  • 写错了、漏了 每页页脚都有「在 GitHub 上改这一页」和「提个 issue」两个入口，直接改、直接提都行，不用先打招呼。
  • 补当地资料 各地在用哪个频率、当地中继和网关的呼号，这些只有本地人清楚。发到群里或开个 issue，整理好就加进「上手与设备」那一页。
  • 投稿教程 自己的折腾过程、踩过的坑、一张能照着接的线图，都欢迎。写得啰嗦没关系，别人能照着做出来就行。
  • 一起聊 QQ 群 925025834，报呼号、问参数、约通联都在这儿。
  • 开个 issue 报错、补资料、加教程，都从这儿开始。 ↗
