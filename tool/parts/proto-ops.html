安全与运行维护

连接限制、管理接口、日志保存、重启恢复，四件事的下限要求。

7.1 接入安全 SERVER 应设置合理的连接数限制、登录超时、报文长度限制和输入速率限制。对于异常连接，可以实施限速、拒绝或断开处理。

7.2 管理接口安全 MANAGER 的管理接口应与普通客户端接入接口相互隔离。管理操作必须经过身份认证和权限检查，管理凭据不得通过未受保护的连接传输。

7.3 日志管理 系统可以记录登录结果、授权变更、白名单同步状态、异常连接和关键运行错误。日志应遵循最小必要原则，并明确访问权限及保存期限。不应默认长期保存全部 APRS 报文内容。

7.4 故障恢复 SERVER 应监控白名单版本、最近同步时间及关键运行状态。服务重启后，应先验证配置和授权数据的完整性，再恢复正常接入。当管理服务不可用或授权数据失效时，应按照预先制定的策略处理新连接。
