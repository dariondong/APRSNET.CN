一条 filter 怎么写

过滤器是给服务器看的订阅单。端口默认给你的那点数据之外，想多看什么，一条条写上去。

写法只有一种：先写 filter，后面跟一个或多个条件，中间用空格隔开。想要达拉斯周边两百公里内的台站，再加上所有 NWS 公报，就写成下面这样。

  • 两个条件 filter r/33/-97/200 t/n 条件之间是「或」的关系，任意一条命中，这个包就推给你。再多几个条件，照样用空格隔开。
  • 加上排除 filter m/200 -p/CW 条件前面加一个减号就是排除。这一行要两百公里内的台站，但呼号以 CW 开头的一个不要。

不写过滤条件，不等于什么都收不到。14580 这个自定义过滤端口上，服务器本来就会给你两样：发给你的消息连同相关的位置包，还有你自己那台网关收上来的包。其余的都要靠过滤条件加上去。排除条件只挡这一个订阅里的包，端口的常规功能照旧，别人发给你的消息不会被它掐掉。

过滤器只管发给你这一个方向。你自己发的包、你自己的网关转上去的包，都不受它约束。

  • 写在哪里 三个地方都认：写在登录行里，给 SERVER 发一条 APRS 消息，或者单独一行注释 #filter r/33/-97/200。官方推荐第一种，现在的客户端基本都支持。
  • 经纬度 一律用十进制度。西经和南纬写负数，东经和北纬写正数。
  • 恢复默认 filter default 让过滤器退回这个端口预设的那一套。
  • 条数 按位置挑的那几类条件，同类里各最多九条。
