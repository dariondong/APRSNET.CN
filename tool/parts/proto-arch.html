系统组成

系统里只有两个角色：SERVER 管接入和转发，MANAGER 管谁有资格接入。

2.1 APRSNET CN SERVER SERVER 是系统的核心接入与转发服务，负责以下工作。

  • 接收连接 接收客户端 TCP 连接。
  • 解析登录 解析客户端登录指令。
  • 登录校验 执行登录格式和必要的 Passcode 校验。
  • 判断授权 查询本地白名单并判断呼号授权状态。
  • 收发报文 接收和检查 APRS 报文。
  • 分发数据 根据客户端订阅规则分发数据。
  • 处理异常 处理异常连接、超时和报文格式错误。
  • 记录日志 维护运行状态并记录必要的安全日志。

SERVER 应当能够独立完成实时转发，不应要求 MANAGER 参与每条报文的处理。

2.2 APRSNET CN MANAGER MANAGER 是系统的管理服务，负责以下工作。

  • 申请与审核 呼号授权申请与审核。
  • 维护名单 白名单维护及授权状态管理。
  • 有效期管理 授权生效、过期、暂停和撤销管理。
  • 同步名单 向 SERVER 同步白名单。
  • 查询与审计 提供必要的管理查询和操作审计。
  • 维护规则 维护授权规则及相关配置。

2.3 职责分离 MANAGER 负责决定哪些呼号具有接入资格，SERVER 根据本地有效白名单执行准入判断。

这种设计可以减少实时转发对管理服务可用性的依赖，并降低管理操作对正常通信的影响。
