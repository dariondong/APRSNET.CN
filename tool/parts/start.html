常用工具

工具不多，够用就行：地图、客户端、数据查询，和一个能找到人的地方。

  • APRS.TV 实时地图 国内爱好者做的实时地图，信标和轨迹回放都能看，站上还带一份中文指南。 ↗
  • APRSLocus 中文界面的开源客户端，Android 与 Windows 可用。 ↗
  • 官方 TOCALL 查询 报文里「呼号 > 这一段」到底是什么设备？粘进去就查得到。 →
  • APRS 符号表 位置包里那两个字定出地图上的图标，主表与替补表一格一格对照着看。 →
  • APRS-IS 中文文档 端口怎么选、登录行怎么写，按官方文档整理成了中文。 →
