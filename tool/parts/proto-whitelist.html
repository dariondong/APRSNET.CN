白名单管理与同步

哪些呼号能进由 MANAGER 决定，名单怎么记、怎么更新、怎么同步给 SERVER。

4.1 授权审核 MANAGER 负责制定并执行呼号授权审核规则。

涉及操作证、电台执照或其他证明材料时，应结合具体业务和适用规定明确审核要求。社团背书可以在符合审核规则时作为辅助材料，但不得自动替代依法要求的许可或资质。

4.2 白名单记录 白名单记录应至少包含呼号、授权状态、授权生效时间、授权失效时间、记录版本和最近更新时间。

4.3 授权状态 授权状态至少包括待审核、已授权、已过期、已暂停和已撤销五种。只有符合当前授权规则且处于有效期内的记录，才可以用于放行新的客户端连接。

4.4 白名单同步 MANAGER 应支持向 SERVER 发布全量或增量白名单更新。更新数据应包含明确的版本信息，并具备完整性校验机制。

SERVER 应验证更新数据的完整性和版本连续性。更新失败时，应保留最后一个有效版本，不得应用不完整的数据。

4.5 授权撤销 授权被撤销或暂停后，MANAGER 应及时发布变更。

SERVER 收到有效变更后，应更新本地授权状态，拒绝相关呼号建立新的未授权会话，并按照规定处理已经建立的连接。

4.6 管理服务不可用 MANAGER 暂时不可用时，SERVER 可以在规定期限内使用最后一次成功加载的白名单。运营方应明确白名单有效期及同步超时后的处理策略，不得无限期地将失效授权视为有效。
