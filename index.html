APRSNET.CN

信标不止，回响不息。

把呼号、位置和一句短消息发到空中，别人就能看见你。

先看看 APRS 是什么 看看怎么上手
  1. 你是一个点 一个呼号、一个位置，就是你在 APRS 里的全部身份。
  2. 发一次信标 把这一行位置包送到空中，附近的中继听见，再一跳一跳往外推。
  3. 就在网里被看见 包汇进这张大网，别人的地图上就多出一个会动的点，那就是你。

APRS 是什么

把位置、天气和一句话消息打成短数据包，用业余无线电频率发出去，让听得见的人接力转发。

全称 Automatic Packet Reporting System，中文常译作「自动分组报告系统」，由 WB4APR（Bob Bruninga）在上世纪八十年代提出。它不依赖互联网：一台电台加一个终端，每个包里都带着呼号，谁收到，谁就能把它显示出来。

  • 中继接力 架在山顶或楼顶的中继台收到包就原样再发一遍，APRS 靠的是大家接力，把覆盖一圈圈推远。
  • 网关（iGate / APRS-IS） 联网的网关把空中收到的包送进互联网，也把互联网上的消息发回空中；地图网站上的数据，就是从这条链路来的。互联网那一侧怎么接，见APRS-IS 中文文档。
  • 不只是位置 短消息、天气、遥测、应急通信都跑在同一条链路上。没有基站，也没有流量，它照样能通，只是慢一点、话少一点。
  • 信标怎么发、参数怎么填 从呼号、坐标到频率与路径，一步步发出你的第一个包。 →

常用工具

工具不多，够用就行：地图、客户端、数据查询，和一个能找到人的地方。

  • APRS.TV 实时地图 面向中国爱好者的 APRS 实时地图：实时信标、轨迹回放、报文解码，还带中文指南。 ↗
  • APRSdroid Android 上的开源客户端：看台站、发短消息、找附近的中继。 ↗
  • YAAC 电脑上的客户端（Java 写的），Windows / macOS / Linux 都能跑。 ↗
  • APRSLocus 中文界面的开源客户端，Android 与 Windows 可用。 ↗
  • APRS-IS 服务器列表 互联网侧的服务器、端口与过滤器说明；想自己写个客户端，从这里看起。 ↗
  • APRS-IS 中文文档 端口怎么选、登录行怎么写、UDP 与只发端口，按官方原文整理成中文。 →
