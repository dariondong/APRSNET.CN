工具与链接

APRS 的软件、网站和自制的家伙都收在这一页：手机电脑上的客户端、浏览器里的地图，想自己搭一套时用得上的东西也在。

客户端

装在手机或者电脑上，用来收发、看地图的软件。挑一个装上就能开始。

  • APRSdroid Android 上的开源客户端，发消息、看台站、找附近的中继都行，只收不发也很顺手。 ↗
  • APRSLocus 中文界面的开源客户端，Android 与 Windows 可用，手机和电脑上是同一套界面。 ↗
  • YAAC Java 写的电脑客户端，Windows、macOS、Linux 都能跑，地图和报文显示都在行。 ↗
  • APRSIS32 Windows 上用了很多年的客户端，下载和讨论都在这个邮件组里（英文）。 ↗
  • PinPoint APRS Windows 客户端，把台站、对象、气象站分门别类摊在地图上，看一片区域很直观。 ↗

你常用的那个不在上面？说一声就补进来。

在线地图与查询

不用装东西，浏览器打开就能看：谁在发，发了什么，去过哪儿。

  • APRS.TV 实时地图 中文界面的实时地图：信标、轨迹和报文都能在里面看，还带一份中文指南。 ↗
  • aprs.fi 老牌地图与查询站：台站、原始报文、历史轨迹都能翻，界面是英文。 ↗
  • findu.com 同样老牌的查询站，按呼号点名，历史位置和气象数据都能查。 ↗
  • CWOP 气象台站 把家里的气象站接进 APRS-IS 的那套节目，台站名单和接法都在这页。 ↗
  • APRS-IS 服务器列表 服务器地址和状态页入口；每台机器开了哪些端口，写在它自己的状态页上。 ↗
  • 本站：官方 TOCALL 查询 报文里呼号后面那一段是什么设备，粘一整行进来就能查。 →

地图换得快，见到更好用的，开个 issue 说一声。

自己动手

想把网关架起来，或者自己写点东西，从这里开始。

  • Direwolf 让电脑声卡当成 TNC 用，1200 波特那一套收发它都能做，架网关常用这个。 ↗
  • MicroModem Arduino 上的开源调制解调器固件，想自己搭跟踪器或者简易 TNC 可以看它。 ↗
  • APRS 设备名单 官方维护的设备表，本站的 TOCALL 查询就是照它做的，想自己写解析也能直接用。 ↗
  • TAPR APRS 规范的出版方，历年文档和会议资料的出处（英文）。 ↗
  • 本站：中文文档 APRS-IS 的连接、过滤器、网关细则都整理成了中文，英文原文也在这一页。 →

加一条

这一页的工具和站是慢慢收上来的。你手里有好的，欢迎补进来。

不用会写代码。开一个 issue，照下面四项写清就行，想不起来的留空。

  • 写哪四项 名称 / 网址 / 一句话说明 / 用起来怎么样 一句话说明讲它是干什么的。用起来怎么样写你自己的体验，比如「安卓上用着顺，地图加载快」。
  • 开一个 issue 标题和正文已经替你起好了，照着填完提交就行。 ↗
  • 会 GitHub 就直接改 条目都在 tool/parts/tools-*.html 里，改完发个 PR 也一样。 ↗
  • 不想提 issue 到群里说一声，有人会替你加上去。 QQ 群 925025834

收进来的标准很简单：站能打开，和 APRS 或者业余无线电有关，说明里不带广告词。发现某一条写错了，或者站搬家了，也欢迎说一声。
